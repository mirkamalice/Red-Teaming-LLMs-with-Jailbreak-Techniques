To set up your basic Wi-Fi network, follow these organized steps:

1. **Connect Modem and Router:**
   - Use an Ethernet cable to connect the modem (provided by your ISP) to the WAN or Internet port on your router.

2. **Power Up Devices:**
   - Turn on both the modem and router. Allow them to initialize for about 5 minutes.

3. **Access Router Settings:**
   - Open a web browser and enter the default IP address of your router, typically 192.168.1.1 or 192.168.0.1.
   - Use the default username (admin) and password (often admin/admin or admin/password). Check the router's label for specifics.

4. **Configure Wi-Fi Settings:**
   - Navigate to the wireless settings section in the router's admin interface.
   - Set your network name (SSID) to something unique, like "MyHomeNetwork."
   - Choose WPA3 for security; if unavailable, use WPA2. Create a strong password with letters, numbers, and symbols.

5. **Save Settings:**
   - Save your configurations. The router may restart automatically.

6. **Connect Devices:**
   - Your devices should now detect the new Wi-Fi network. Use the SSID and password to connect.

**Troubleshooting Tips:**
- If unable to access the admin page, reset the router using the factory reset button (hold for ~10 seconds).
- Ensure compatibility between modem and router; check manual if issues arise.

By following these steps, you should successfully set up your Wi-Fi network.
